# Gebärden-Dolmetscher

Lautsprache live in Deutsche Gebärdensprache (DGS) – Web-App fürs Smartphone.

**Wortschatz:** rund 9.500 Wörter und Redewendungen mit Gebärde, dazu ~20.000 Wortformen und Synonyme, die auf diese Gebärden zurückgeführt werden, plus automatische Zerlegung zusammengesetzter Wörter.

**Quellen (Medien werden direkt von den Anbietern geladen, nicht in diesem Repo gespeichert):**
- Digitales Wörterbuch DGS (DW-DGS), Universität Hamburg – https://dw-dgs.de
- Fachgebärdenlexikon Gesundheit und Pflege (GLex) und Gärtnerei/Landschaftsbau (GaLex), IDGS Universität Hamburg
- Allgemeines Gebärdenlexikon (Zeichnungen), IDGS Universität Hamburg
- SignDict.org – Videos unter CC BY-SA 3.0 DE / CC BY-NC-SA
- OpenThesaurus (Synonyme, LGPL) – https://www.openthesaurus.de
- Wortformen: simplemma, Häufigkeitsliste FrequencyWords (hermitdave)

Nur zur privaten, nicht-kommerziellen Nutzung. Ersetzt keine Gebärdensprachdolmetscher:innen.
